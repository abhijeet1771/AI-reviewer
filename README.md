# Test Java Project

Simple Java project for testing AI code reviewer.

## Files

- `HelloWorld.java` - Basic hello world program
- `Calculator.java` - Simple calculator with some potential issues

## How to Run

```bash
javac HelloWorld.java
java HelloWorld
```

## Testing AI Code Reviewer

1. Create a PR with changes to these files
2. Use the AI code reviewer to analyze the PR
3. See what issues it finds!
